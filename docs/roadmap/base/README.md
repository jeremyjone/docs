# 计算机基础

计算机基础是计算机科学的重要基石。只有充分掌握了计算机的基础理论部分，才可以更快、更好地学习更高级的知识。

## 内容导航

按顺序阅读效果最佳：

1. **[计算机基础](/roadmap/base/computer/)**——计算机发展史、冯·诺依曼架构、数据表示、操作系统概述
2. **[网络基础](/roadmap/base/network/)**——OSI 模型、TCP/UDP、IP 地址、DNS、HTTP/HTTPS
3. **[数据结构](/roadmap/base/data-structure/)**——数组、链表、栈、队列、树、哈希表、图
4. **[算法](/roadmap/base/algorithm/)**——复杂度分析、排序、查找、动态规划、图算法
5. **[数据库基础](/roadmap/base/database/)**——关系型数据库、SQL、事务 ACID、索引、NoSQL

> 以上内容面向入门到进阶，每篇都独立可读，但按顺序阅读体验更连贯。
