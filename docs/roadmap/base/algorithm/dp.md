# 动态规划

动态规划（Dynamic Programming，DP）把大问题拆成**重叠子问题**，每个子问题只计算一次，结果存起来复用。

---

## 核心思路

### 几种方案的演进

| 方案 | 思路 | 复杂度 |
|------|------|--------|
| 朴素递归 | 直接递归，大量重复计算 | O(2ⁿ) |
| 记忆化递归 | 递归 + 缓存已计算结果（自顶向下） | O(n) |
| 动态规划 | 从小往大迭代填表（自底向上） | O(n) |

---

## 分步拆解：斐波那契数列 F(5)

斐波那契数列定义：
```
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2)   (n ≥ 2)
```

### 朴素递归（低效）

```
          F(5)
         /    \
      F(4)    F(3)
     /   \    /   \
   F(3)  F(2) F(2) F(1)
   /  \  / \  / \
 F(2)F(1)F(1)F(0)F(1)F(0)
 / \
F(1)F(0)
```

F(3) 算了 2 次，F(2) 算了 3 次，F(1) 算了 5 次——大量重复。

### 动态规划（自底向上填表）

```
F(0) = 0          ← 已知
F(1) = 1          ← 已知

F(2) = F(1) + F(0) = 1 + 0 = 1
F(3) = F(2) + F(1) = 1 + 1 = 2
F(4) = F(3) + F(2) = 2 + 1 = 3
F(5) = F(4) + F(3) = 3 + 2 = 5  ✅
```

每个子问题只算一次，存下来给后面用。

## 伪代码

### 动态规划（自底向上填表）

```text
function fibonacci(n):
    if n <= 1:
        return n

    dp = new int[n+1]
    dp[0] = 0
    dp[1] = 1

    for i = 2 to n:
        dp[i] = dp[i-1] + dp[i-2]

    return dp[n]
```

### 空间优化版

只用两个变量，空间从 O(n) 降到 O(1)：

```text
function fibonacci(n):
    if n <= 1:
        return n

    prev2 = 0   // F(i-2)
    prev1 = 1   // F(i-1)

    for i = 2 to n:
        curr = prev1 + prev2
        prev2 = prev1
        prev1 = curr

    return prev1
```

## 复杂度对比

| 方案 | 时间 | 空间 |
|------|------|------|
| 朴素递归 | O(2ⁿ) | O(n) 栈空间 |
| 记忆化递归 | O(n) | O(n) |
| 动态规划（填表） | O(n) | O(n) |
| 动态规划（空间优化） | O(n) | O(1) |

## DP 的思考步骤

1. **确认最优子结构** — 大问题的最优解是否包含小问题的最优解
2. **定义状态** — `dp[i]` 表示什么（如"到第 i 天的最大收益"）
3. **找状态转移方程** — `dp[i] = f(dp[i-1], dp[i-2], ...)`
4. **确定初始值** — `dp[0]`、`dp[1]` 等基本情况
5. **按顺序计算** — 从小到大批量计算

---

## 经典 DP 问题

| 问题 | 状态定义 | 转移方程 |
|------|---------|---------|
| 斐波那契 | `dp[n]` = 第 n 项 | `dp[n] = dp[n-1] + dp[n-2]` |
| 爬楼梯 | `dp[n]` = 到 n 阶的方法数 | `dp[n] = dp[n-1] + dp[n-2]` |
| 最大子数组和 | `dp[i]` = 以 i 结尾的最大和 | `dp[i] = max(nums[i], dp[i-1] + nums[i])` |
| 背包问题 | `dp[i][w]` = 前 i 个物品容量 w 的最大价值 | `dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi] + vi)` |

> DP 是算法面试中出现频率最高的题型。掌握"状态定义 + 转移方程"这个思考框架，比机械记忆题目更重要。
