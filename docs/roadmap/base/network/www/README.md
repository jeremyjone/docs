# 万维网

万维网（World Wide Web，简称 WWW）是互联网上最广泛使用的信息服务体系。它由英国科学家 Tim Berners-Lee 在 1989 年发明，让互联网从一个仅限科研的通信网络变成了普通人也能访问的信息海洋。

> **注意区分**：互联网（Internet）是物理网络基础设施，万维网（WWW）是构建在它之上的信息服务平台。互联网还包括邮件、FTP、即时通讯等服务。

## 万维网的三大基石

### 1. HTML（超文本标记语言）

定义网页的结构和内容。超文本意味着页面中可以通过链接跳转到其他页面。

### 2. HTTP/HTTPS（超文本传输协议）

定义浏览器和服务器之间如何通信。HTTP 是明文，HTTPS 在 HTTP 上加了 TLS/SSL 加密。

### 3. URL（统一资源定位符）

定义资源在 Web 上的唯一地址。一个标准的 URL 结构：

```text
https://docs.jeremyjone.com:443/roadmap/base/network/www/?q=hello#intro
└─┬─┘ └─────────┬─────────┘ └┬┘└──────────┬──────────┘└──┬──┘└──┬─┘
  协议            域名         端口         路径          参数    锚点
```

> URL、URI、URN 的区别在 [URL](/roadmap/base/network/www/url.md) 专篇有详细说明。

## 浏览器的工作原理

浏览器是用户访问万维网的工具，一个简化的请求流程：

1. **地址栏输入 URL** → 解析协议、域名、路径
2. **DNS 解析** → 域名转 IP
3. **建立 TCP 连接** → 三次握手（HTTPS 还需要 TLS 握手）
4. **发送 HTTP 请求** → GET /index.html
5. **服务器响应** → 返回 HTML + 状态码（200、404 等）
6. **浏览器渲染** → 解析 HTML → 构建 DOM 树 → 加载 CSS/JS → 渲染页面
7. **后续请求** → 页面中的图片、样式、脚本都会触发新的 HTTP 请求

## 万维网 vs 互联网

| | 互联网 | 万维网 |
|--|--------|--------|
| 范围 | 基础设施 | 服务之一 |
| 包含 | 所有网络协议和设备 | HTTP 协议 + HTML 页面 |
| 类比 | 公路系统 | 公交系统 |
| 典型服务 | 邮件、P2P、即时通讯 | 网页浏览 |

## Web 简史

- **Web 1.0**（1990s~2000s）：静态网页，只读，用户是内容消费者
- **Web 2.0**（2000s~2010s）：动态交互，UGC，AJAX 兴起（博客、社交、视频）
- **Web 3.0**（2010s~至今）：语义化、去中心化、AI 驱动
