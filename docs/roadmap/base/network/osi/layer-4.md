# 四层模型

TCP/IP 四层模型是互联网实际采用的协议栈，它将 OSI 七层合并为四层，更贴近工程实践。

## 4 - 应用层

对应 OSI 的应用层、表示层、会话层。所有应用层协议都直接在这层实现。

**特点**：协议数量最多，按需选用。每个协议解决一类具体问题。

**常见协议**：

| 协议 | 用途 | 端口 |
|------|------|------|
| HTTP | 网页浏览 | 80 |
| HTTPS | 加密网页浏览 | 443 |
| FTP | 文件传输 | 20/21 |
| DNS | 域名解析 | 53 |
| SMTP | 邮件发送 | 25 |
| SSH | 安全远程登录 | 22 |

## 3 - 传输层

与 OSI 传输层对应，提供端到端的通信服务。核心是两个协议：

**TCP**（传输控制协议）
- 面向连接，可靠传输
- 保证数据按序到达
- 支持流量控制和拥塞控制
- 适用于网页浏览、文件下载、邮件

**UDP**（用户数据报协议）
- 无连接，不可靠但高效
- 不保证顺序，不重传
- 低延迟
- 适用于视频直播、在线游戏、DNS 查询

> 两个协议的详细对比见 [TCP](/roadmap/base/network/protocol/tcp.md) 和 [UDP](/roadmap/base/network/protocol/udp.md) 专篇。

## 2 - 网络层

与 OSI 网络层对应，核心是 IP 协议（网际协议）。

**核心功能**：
- IP 地址编址与寻址
- 路由选择与分组转发
- 分片与重组（适应不同链路层 MTU）

**辅助协议**：
- ICMP：差错报告（ping、traceroute 的基础）
- ARP：IP 地址 → MAC 地址映射
- NAT：私有 IP ↔ 公网 IP 转换

## 1 - 网络接口层

对应 OSI 的数据链路层和物理层，负责在物理网络上传输数据。

**功能**：
- MAC 地址寻址
- 帧封装与差错校验
- 比特流传输

**常见技术**：以太网、Wi-Fi、光纤、DSL

## OSI 与 TCP/IP 核心差异

| 对比维度 | OSI 七层 | TCP/IP 四层 |
|---------|----------|-------------|
| 诞生时间 | 理论先于实现 | 实现先于模型 |
| 分层数量 | 7 | 4 |
| 会话层/表示层 | 独立 | 合并到应用层 |
| 物理层/数据链路层 | 独立 | 合并到网络接口层 |
| 使用范围 | 教学参考标准 | 实际互联网协议 |
| 协议绑定 | 未定义具体协议 | 已绑定 TCP/IP 协议族 |

> **一句话总结**：OSI 七层是"理论"，TCP/IP 四层是"实践"。面试问分层知识时讲 OSI，做网络排错时按 TCP/IP。
