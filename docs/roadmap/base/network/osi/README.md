# OSI 模型

OSI（Open System Interconnection，开放系统互连）模型是国际标准化组织（ISO）在 1984 年发布的网络通信参考模型。它将计算机网络通信划分为 **七层**，每层负责独立的功能，层与层之间通过标准接口交互。

## 为什么需要分层

网络通信是一个极其复杂的过程——数据要从一台设备的应用程序出发，经过网线、路由器、交换机，最终到达另一台设备的应用程序。分层设计把复杂问题拆成若干小问题：

- 每一层只关注自己的职责，实现解耦
- 某层改动不影响其他层
- 标准化接口使得不同厂商的设备可以互联互通

## OSI 七层 vs TCP/IP 四层

实际互联网采用的是 **TCP/IP 四层模型**（更精简），OSI 七层模型更多作为理论参考。两者的大致对应关系：

| OSI 七层 | TCP/IP 四层 | 典型协议/设备 |
|----------|-------------|--------------|
| 应用层、表示层、会话层 | 应用层 | HTTP、FTP、SMTP、DNS |
| 传输层 | 传输层 | TCP、UDP |
| 网络层 | 网络层 | IP、ICMP、路由器 |
| 数据链路层、物理层 | 网络接口层 | 以太网、Wi-Fi、交换机、网卡 |

后续章节会分别从**七层模型**和**四层模型**两个视角展开讲解。
