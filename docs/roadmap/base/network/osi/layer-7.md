# 七层模型

OSI 七层模型从上到下依次为：应用层、表示层、会话层、传输层、网络层、数据链路层、物理层。数据发送时从上往下层层封装，接收时从下往上层层解析。

## 7 - 应用层

最接近用户的一层，直接为应用程序提供网络服务。

**功能**：识别通信对象、确定资源可用性、同步通信

**典型协议**：HTTP（网页）、FTP（文件传输）、SMTP（邮件）、DNS（域名解析）、SSH（远程登录）

## 6 - 表示层

负责数据格式的转换，确保一个系统发送的数据能被另一个系统识别。

**功能**：
- 数据格式转换（如 ASCII 与 EBCDIC 互转）
- 数据加密与解密（如 SSL/TLS 握手中的证书协商）
- 数据压缩与解压缩

**典型协议/格式**：SSL/TLS、JPEG、MPEG

## 5 - 会话层

负责建立、管理和终止应用程序之间的会话。

**功能**：
- 建立和释放会话连接
- 会话同步（在数据流中插入检查点，断点续传的基础）
- 对话控制（半双工/全双工模式选择）

## 4 - 传输层

承上启下的关键层，负责端到端的数据传输服务。

**功能**：
- 数据分段与重组
- 差错控制（检测丢包、重传）
- 流量控制（防止发送方过快淹没接收方）
- 端口寻址（区分不同应用程序）

**典型协议**：TCP（可靠）、UDP（不可靠）

## 3 - 网络层

负责数据包从源主机到目标主机的路由选择。

**功能**：
- 逻辑地址寻址（IP 地址）
- 路由选择（选最佳路径）
- 分组转发

**典型协议/设备**：IP（网际协议）、ICMP（ping）、路由器

## 2 - 数据链路层

负责相邻节点之间的数据传输，将网络层的数据包封装成帧。

**功能**：
- 帧封装与同步
- MAC 地址寻址
- 差错检测（CRC 校验），出错则丢弃

**典型协议/设备**：以太网、Wi-Fi（802.11）、交换机

## 1 - 物理层

最底层，负责在物理媒体上传输原始比特流。

**功能**：
- 定义接口的机械、电气特性
- 比特编码与同步
- 传输介质管理

**典型设备**：网线（双绞线）、光纤、集线器、中继器

## 数据封装过程

发送方从第 7 层开始，每经过一层就加上该层的头部信息（部分层还加尾部）：

```
应用层数据 → [AH]应用层数据
表示层 → [PH][AH]应用层数据
...
数据链路层 → [DH][...数据...][DT]
物理层 → 比特流
```

接收方逐层拆解头部，最终把数据交给目标应用程序。

> 尽管 OSI 七层模型更多是理论参考，但它的分层思想深刻影响了所有网络协议的设计。
