# IP 地址

IP 地址（Internet Protocol Address）是网络层用于标识设备（主机或路由器接口）的逻辑地址。它在互联网中唯一标识一台设备，相当于现实世界中的"门牌号"。

## IPv4

IPv4 地址由 32 位二进制数组成，通常用"点分十进制"表示：每 8 位一段，用点分隔。

```
192.168.1.1  →  11000000.10101000.00000001.00000001
```

### 分类编址

传统 IPv4 将地址分为 A/B/C/D/E 五类：

| 类别 | 开头位 | 地址范围 | 默认子网掩码 | 用途 |
|------|--------|---------|-------------|------|
| A 类 | 0 | 1.0.0.0 ~ 126.255.255.255 | 255.0.0.0 | 大型网络 |
| B 类 | 10 | 128.0.0.0 ~ 191.255.255.255 | 255.255.0.0 | 中型网络 |
| C 类 | 110 | 192.0.0.0 ~ 223.255.255.255 | 255.255.255.0 | 小型网络 |
| D 类 | 1110 | 224.0.0.0 ~ 239.255.255.255 | — | 组播 |
| E 类 | 1111 | 240.0.0.0 ~ 255.255.255.255 | — | 保留 |

### CIDR（无类域间路由）

分类编址浪费 IP 空间。CIDR 用 `/前缀长度` 替代固定子网掩码，灵活性更高：

```text
192.168.1.0/24  → 子网掩码 255.255.255.0，256 个地址
10.0.0.0/8      → 子网掩码 255.0.0.0，1677 万个地址
```

### 私有 IP 地址

以下范围仅限局域网使用，不会在互联网路由：

| 类别 | 范围 |
|------|------|
| A 类 | 10.0.0.0/8 |
| B 类 | 172.16.0.0/12 |
| C 类 | 192.168.0.0/16 |

### 特殊地址

- **127.0.0.1**（localhost）：回环地址，指向本机
- **0.0.0.0**：表示本机所有 IP，或默认路由
- **255.255.255.255**：广播地址

## IPv6

IPv6 用 128 位地址，彻底解决地址枯竭问题。采用"冒号十六进制"表示：

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

**简化规则**：
- 每组前导零可省略 → `2001:db8:85a3:0:0:8a2e:370:7334`
- 连续全零段可用 `::` 替代一次 → `2001:db8:85a3::8a2e:370:7334`

IPv6 没有 NAT，每个设备都拥有全球唯一公网地址。

## NAT（网络地址转换）

NAT 让多个设备共享一个公网 IP 上网。路由器把局域网设备的私有 IP + 端口映射到公网 IP + 端口：

```text
192.168.1.10:54321  →  路由器  →  公网 IP:30001
```

优点：缓解 IPv4 地址枯竭、隐藏内网拓扑。
缺点：破坏了端到端原则，P2P 通信需要打洞。

## 子网掩码

子网掩码用来区分 IP 地址的"网络号"和"主机号"：

```text
IP:         192.168.1.10  →  11000000.10101000.00000001.00001010
掩码:       255.255.255.0 →  11111111.11111111.11111111.00000000
网络号:     192.168.1.0   →  11000000.10101000.00000001.00000000
主机号:     0.0.0.10
```

**常用子网掩码速查**：

| CIDR | 子网掩码 | 可用主机数 |
|------|---------|-----------|
| /24 | 255.255.255.0 | 254 |
| /16 | 255.255.0.0 | 65534 |
| /8 | 255.0.0.0 | 16777214 |
| /30 | 255.255.255.252 | 2（点对点链路） |
