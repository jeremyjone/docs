# 队列

队列（Queue）是一种**先进先出（FIFO）**的线性数据结构，队尾入队、队首出队。

---

## 基本操作

| 操作 | 描述 | 复杂度 |
|------|------|--------|
| `enqueue(x)` | 将元素 x 加入队尾 | O(1) |
| `dequeue()` | 移除并返回队首元素 | O(1) |
| `front()` | 查看队首元素（不移除） | O(1) |
| `isEmpty()` | 判断队列是否为空 | O(1) |

## 队列的变种

### 双端队列（Deque）

两端都可以入队和出队。结合了栈和队列的能力。

```js
// 队首操作
deque.unshift(x);  // 队首入队
deque.shift();     // 队首出队

// 队尾操作
deque.push(x);     // 队尾入队
deque.pop();       // 队尾出队
```

### 优先队列（Priority Queue）

入队时按优先级排序，优先级最高的先出队。底层通常用**堆**实现。

常见应用：Dijkstra 最短路径、任务调度、操作系统的进程调度。

### 阻塞队列

- 队列为空时，`dequeue` 操作会阻塞等待
- 队列满时，`enqueue` 操作会阻塞等待

用于**生产者-消费者模型**，是消息队列和线程池的核心组件。

---

## 常见应用场景

| 场景 | 说明 |
|------|------|
| **任务调度** | 按提交顺序处理任务 |
| **消息队列** | 解耦生产者与消费者（如 RabbitMQ、Kafka） |
| **BFS 广度优先搜索** | 按层遍历图或树 |
| **打印队列** | 文档按提交顺序打印 |
| **请求限流** | 排队处理请求，超出队列直接丢弃 |

> 队列和栈是"双胞胎"：队列先进先出，栈后进先出。记住它们的区别，面试常问。
