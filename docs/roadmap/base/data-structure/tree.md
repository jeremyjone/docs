# 树结构

树是一对多的层级数据结构，在文件系统、数据库索引、编译器等领域广泛使用。

---

## 二叉树（Binary Tree）

每个节点最多有两个子节点（左子树、右子树）。

### 遍历方式

| 方式 | 顺序 | 用途 |
|------|------|------|
| 前序 | 根 → 左 → 右 | 序列化树、目录树显示 |
| 中序 | 左 → 根 → 右 | 二叉搜索树有序输出 |
| 后序 | 左 → 右 → 根 | 删除节点、计算表达式 |
| 层序 | 逐层遍历 | BFS、求树的高度 |

---

## 二叉搜索树（BST）

左子树所有节点 < 根节点 < 右子树所有节点。

### 特点

- 查找/插入/删除：平均 O(log n)，最坏 O(n)（退化成链表）
- 中序遍历即有序输出

### 改进方案

| 变种 | 机制 | 保证 |
|------|------|------|
| AVL 树 | 严格平衡（左右子树高度差 ≤ 1） | O(log n) |
| 红黑树 | 近似平衡（5 条染色规则） | O(log n) |

Java 的 `TreeMap`、C++ 的 `std::map` 底层就是红黑树。

## 堆（Heap）

堆是一种完全二叉树，常用于实现优先队列。

| 类型 | 规则 |
|------|------|
| 最大堆 | 父节点 ≥ 子节点（堆顶为最大值） |
| 最小堆 | 父节点 ≤ 子节点（堆顶为最小值） |

### 操作复杂度

| 操作 | 复杂度 |
|------|--------|
| 插入 | O(log n) |
| 删除堆顶 | O(log n) |
| 建堆 | O(n) |

### 适用场景

- Top K 问题（找最大/最小的 K 个元素）
- Dijkstra 最短路径算法
- 任务调度（优先处理优先级最高的任务）
- 中位数维护（两个堆配合）
