# 图的表示

图（Graph）由**顶点（Vertex）**和**边（Edge）**组成，用于表示多对多的复杂关联关系。

---

## 图的类型

| 类型 | 说明 |
|------|------|
| 有向图 | 边有方向（A→B 不等于 B→A） |
| 无向图 | 边无方向（A—B 等同于 B—A） |
| 有权图 | 边带有权重（距离、成本等） |
| 无权图 | 边没有权重，仅表示连通关系 |

---

## 两种表示方式

### 邻接矩阵

```
     A  B  C  D
A   [0, 1, 1, 0]
B   [1, 0, 0, 1]
C   [1, 0, 0, 1]
D   [0, 1, 1, 0]
```

| 维度 | 说明 |
|------|------|
| 空间 | O(V²) — V 为顶点数 |
| 查边 | O(1) — `matrix[i][j]` 直接获取 |
| 遍历邻居 | O(V) — 需要扫描整行 |

**适用**：稠密图（边数接近 V²）

### 邻接表

```
A → B → C
B → A → D
C → A → D
D → B → C
```

| 维度 | 说明 |
|------|------|
| 空间 | O(V + E) — V 为顶点数，E 为边数 |
| 查边 | O(degree) — 需要遍历该顶点的邻居列表 |
| 遍历邻居 | O(degree) — 直接拿到列表 |

**适用**：稀疏图（边数远小于 V²）

---

## 选择依据

| 场景 | 推荐 |
|------|------|
| 顶点少（< 100）、频繁查边 | 邻接矩阵 |
| 顶点多、边少（社交网络） | 邻接表 |
| 需要快速遍历全部邻居 | 邻接表 |
| 需要快速判断两点是否相连 | 邻接矩阵 |

> 图的遍历（BFS、DFS）见 [图遍历](/roadmap/base/algorithm/graph-traversal.html)。
