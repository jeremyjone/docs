# 数组与链表

数组（Array）和链表（Linked List）是最基础的两种线性存储结构，它们在内存布局和操作性能上有根本差异。

---

## 数组（Array）

连续内存空间存储相同类型的数据，支持随机访问。

### 特点

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 访问（按下标） | O(1) | 直接通过内存地址计算，一步到位 |
| 插入 | O(n) | 需要移动后续所有元素腾位置 |
| 删除 | O(n) | 删除后需要前移后续元素 |

- 空间连续，CPU 缓存友好（预读取相邻数据）
- 大小固定（动态数组如 ArrayList 底层仍是固定数组+扩容）

### 适用场景

数据量固定、频繁读取、少量修改

---

## 链表（Linked List）

节点通过指针串联，非连续存储。

### 种类

- **单向链表**：每个节点存 data + next 指针
- **双向链表**：每个节点存 data + prev + next 指针
- **循环链表**：尾节点的 next 指向头节点

### 特点

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 访问 | O(n) | 必须从头遍历 |
| 插入（已知位置） | O(1) | 改前后节点的指针 |
| 删除（已知位置） | O(1) | 跳过当前节点 |

### 适用场景

频繁插入删除、数据量动态变化

## 对比总结

| 维度 | 数组 | 链表 |
|------|------|------|
| 内存布局 | 连续 | 分散 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1) |
| 额外空间 | 无 | 每个节点多存 1~2 个指针 |
| 缓存友好 | 是 | 否 |

> 没有哪个绝对更好，取决于场景：读多写少用数组，写多读少用链表。
