# 数据结构

数据结构（Data Structure）是计算机存储和组织数据的方式。选择合适的数据结构，可以直接影响程序的性能和复杂度。

> 程序 = 数据结构 + 算法。数据结构是"容器"，算法是"操作容器的方法"。

## 线性结构

### 数组（Array）

连续内存空间存储相同类型的数据，支持随机访问。

**特点**：
- 访问：O(1)（通过下标）
- 插入/删除：O(n)（需要移动元素）
- 空间连续，CPU 缓存友好

**适用场景**：数据量固定、频繁读取、少量修改

### 链表（Linked List）

节点通过指针串联，非连续存储。

**种类**：
- 单向链表：每个节点存 next 指针
- 双向链表：每个节点存 prev 和 next 指针
- 循环链表：尾节点指向头节点

**特点**：
- 访问：O(n)（需要遍历）
- 插入/删除：O(1)（已知节点位置时）
- 不需要连续内存

**适用场景**：频繁插入删除、数据量动态变化

### 栈（Stack）

后进先出（LIFO），只能在栈顶操作。

**操作**：`push`（入栈）、`pop`（出栈）、`peek`（查看栈顶）

**适用场景**：函数调用栈、括号匹配、撤销操作

<img :src="$withBase('/assets/roadmap/base/stack.svg')" alt="栈结构示意图" style="max-width:100%;margin:20px 0;">

### 队列（Queue）

先进先出（FIFO），队尾入队、队首出队。

**种类**：
- 普通队列：FIFO
- 双端队列（Deque）：两端都可进出
- 优先队列（Priority Queue）：按优先级出队（用堆实现）
- 阻塞队列：队列为空时入队阻塞、队列满时出队阻塞（生产者-消费者模型）

**适用场景**：任务调度、消息队列、BFS

## 树形结构

### 二叉树（Binary Tree）

每个节点最多有两个子节点（左子树、右子树）。

**遍历方式**：

| 方式 | 顺序 | 用途 |
|------|------|------|
| 前序 | 根 → 左 → 右 | 序列化树、目录树显示 |
| 中序 | 左 → 根 → 右 | 二叉搜索树有序输出 |
| 后序 | 左 → 右 → 根 | 删除节点、计算表达式 |
| 层序 | 逐层遍历 | BFS、求树的高度 |

### 二叉搜索树（BST）

左子树所有节点 < 根节点 < 右子树所有节点。

**特点**：
- 查找/插入/删除：平均 O(log n)，最坏 O(n)（退化成链表）
- 中序遍历即有序输出

**改进**：AVL 树、红黑树——在插入删除时自动保持平衡，确保 O(log n)

<img :src="$withBase('/assets/roadmap/base/binary-tree.svg')" alt="二叉树结构示意图" style="max-width:100%;margin:20px 0;">

### 堆（Heap）

完全二叉树，常用于实现优先队列。

- **最大堆**：父节点 >= 子节点（堆顶最大）
- **最小堆**：父节点 <= 子节点（堆顶最小）

**操作**：插入 O(log n)、删除堆顶 O(log n)、建堆 O(n)

**适用场景**：Top K 问题、Dijkstra 算法、任务调度

## 散列结构

### 哈希表（Hash Table / HashMap）

通过哈希函数将 key 映射到存储位置，实现近似 O(1) 的查找。

**哈希冲突解决**：
- **链地址法**：每个槽位存一个链表（Java HashMap 的方式）
- **开放寻址法**：冲突时找下一个空位（ThreadLocal 的方式）

**适用场景**：缓存、字典、去重

## 图的表示

- **邻接矩阵**：V x V 矩阵，直观但占用 O(V²) 空间
- **邻接表**：每个节点存一个邻居列表，稀疏图节省空间

## 如何选择数据结构

| 核心操作 | 推荐结构 |
|---------|---------|
| 按索引快速访问 | 数组 |
| 频繁插入删除 | 链表 |
| 后进先出 | 栈 |
| 先进先出 | 队列 |
| 快速查找 | 哈希表 |
| 有序存储 + 快速查找 | 二叉搜索树 |
| 快速取最大/最小值 | 堆 |
| 层级关系 | 树 |
| 复杂关联关系 | 图 |

> 选数据结构的口诀：**访问用数组，增删用链表，查找用哈希，顺序用树，极值用堆。**
