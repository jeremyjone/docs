# 算法

算法（Algorithm）是解决特定问题的一系列明确步骤。程序 = 数据结构 + 算法，两者相辅相成——数据结构组织数据，算法处理数据。

本节是算法的入门导览，帮助建立概念框架。每个算法都值得单独深入。

# 算法的衡量：复杂度

算法好坏主要用时间复杂度和空间复杂度来衡量，用大 O 表示法描述：

大 O 名称 示例算法
O(1) 常数时间 数组随机访问
O(log n) 对数时间 二分查找
O(n) 线性时间 遍历数组
O(n log n) 线性对数 归并排序、快速排序
O(n²) 平方时间 冒泡排序、嵌套循环
O(2ⁿ) 指数时间 朴素斐波那契递归

经验：n 较小时 O(n²) 也能接受；n 大于 10⁵ 时 O(n log n) 是最优选择；O(2ⁿ) 只有 n 很小时才可用。

# 常见算法分类

# 排序算法

算法 平均时间复杂度 空间复杂度 稳定 特点
冒泡排序 O(n²) O(1) ✓ 最简单，但不推荐用于大数据
选择排序 O(n²) O(1) ✗ 不稳定，但交换次数少
插入排序 O(n²) O(1) ✓ 小规模数据或近似有序时很快
归并排序 O(n log n) O(n) ✓ 稳定但需要额外空间
快速排序 O(n log n) O(log n) ✗ 平均最快，但最坏退化为 O(n²)
堆排序 O(n log n) O(1) ✗ 原地排序，不退化

# 查找算法

  • 线性查找：O(n)，适用于无序数据
  • 二分查找：O(log n)，要求数据已排序
  • 哈希查找：O(1) 平均，需要哈希表

# 递归与分治

  • 递归：函数调用自身，核心是找到递推公式和终止条件
  • 分治：把大问题分解成小问题，解决小问题后合并结果（典型：归并排序）

# 动态规划

核心思想：将问题分解为重叠子问题，每个子问题只计算一次，结果存起来复用（备忘录/DP 表）。

经典问题：斐波那契数列、背包问题、最长公共子序列、最短路径

# 贪心算法

每步都选择当前最优，最终得到全局最优解——但前提是该问题具有最优子结构。

经典问题：找零钱（特定货币体系）、哈夫曼编码、最小生成树（Prim/Kruskal）

# 图算法

  • BFS（广度优先搜索）：最短路径（无权图）
  • DFS（深度优先搜索）：连通性检测、拓扑排序
  • Dijkstra：单源最短路径（带权图，无负边）
  • A*：启发式搜索，路径规划常用

# 实践建议

  1. 优先掌握排序 + 二分查找 + 递归 + BFS/DFS，这是面试和日常开发最高频的
  2. 刷题按题型刷（数组、链表、树、动态规划），不要按算法名刷
  3. 写算法时先确定边界条件（空输入、负值、最大值溢出）
  4. 复杂度分析不是理论推导，而是估算——最关心的通常是 n 很大时的表现

结合 数据结构 一起学习，效果更好。
