# 计算机基础内容

计算机基础是学习计算机科学的起点，涵盖计算机的起源、硬件组成和数据表示等核心知识。

本节内容偏概述，目的是建立对计算机的整体认知。

# 计算机的发展

电子管时代（1940s~1950s）：ENIAC 等第一代计算机，用电子管作为逻辑元件，体积大、功耗高、速度慢。

晶体管时代（1950s~1960s）：用晶体管替代电子管，体积缩小、可靠性提升。

集成电路时代（1960s~1970s）：把多个晶体管集成到一块芯片上，体积和成本大幅下降。

大规模/超大规模集成电路时代（1970s~至今）：一片芯片上集成数十亿晶体管，个人计算机和智能手机普及。

# 计算机组成（冯·诺依曼架构）

现代计算机基本都遵循冯·诺依曼架构：

  • 运算器：负责算术运算和逻辑运算
  • 控制器：取指令、解码、执行，协调各部件工作
  • 存储器：保存指令和数据（内存 + 外存）
  • 输入设备：键盘、鼠标、网卡等
  • 输出设备：显示器、打印机等

核心思想：程序和数据都放在存储器中，计算机自动逐条执行指令。

# 数据在计算机中的表示

所有数据在计算机中最终都是二进制（0 和 1）。

比特（bit）：最小单位，表示 0 或 1 字节（byte）：1 字节 = 8 比特，是存储的基本单位

单位 大小 大致容量
1 KB 1024 字节 一段短文本
1 MB 1024 KB 一张照片
1 GB 1024 MB 一部电影
1 TB 1024 GB 一块硬盘

常见编码：

  • ASCII：7 位编码 128 个字符（英文字母、数字、符号）
  • Unicode：统一编码全球所有字符，UTF-8 是其在网络上最常用的实现
  • GBK：中文编码标准，兼容 ASCII

# 操作系统

操作系统是管理计算机硬件和软件资源的系统软件，是用户和硬件之间的桥梁。

主要职责：

  • 进程管理（CPU 调度）
  • 内存管理（分配与回收）
  • 文件系统（数据持久化）
  • 设备驱动（管理硬件）
  • 网络协议栈

常见操作系统：Windows、macOS、Linux、Android、iOS

后续的 数据结构、算法、网络、数据库 等内容都依赖于这里的基础概念。
